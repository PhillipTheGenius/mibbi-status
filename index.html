    What these checks cover

    The monitor opens the public website, sign-in page, Help centre and Security page. It also checks that a signed-out request cannot list private builder projects. Checks are scheduled about every 10 minutes; GitHub can delay them. Results older than 25 minutes are shown as out of date.

    These checks do not log in, buy anything, run a paid AI request or test every customer website. A reachable sign-in page does not prove that signing in works. Payments, authenticated database actions, email delivery, AI generation and customer-specific problems need separate investigation.
